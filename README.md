**📝 To-Do List**

This is a simple and clean To-Do List web application built using HTML, CSS, and JavaScript.

The main purpose of this project is to manage daily tasks in an easy way. Users can add tasks, edit them, delete them, and mark them as completed.


**✨ Features**

- Add new tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Filter tasks (All / Completed / Pending)
- Tasks are saved in browser using Local Storage

Even if you refresh the page, your tasks will not disappear.
